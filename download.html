How to install

  1. Tap Download for Android and accept the download prompt.
  2. Open the downloaded file.
  3. If Android asks, allow Install unknown apps for your browser, then go back and tap Install.
  4. If Play Protect shows a warning, tap More details, then Install anyway.

The app is not on Google Play yet, so Android shows these extra prompts. They are normal for apps installed from a website.
